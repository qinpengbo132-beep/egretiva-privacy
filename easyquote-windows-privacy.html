Easy Quote · Windows Privacy Policy

Windows edition · Updated 2026-10-18

Local business records / 本机业务资料

Company, bank-account, customer, product/equipment, image, project and QT/PI/CI document data are stored on your Windows computer, together with saved revisions, local previews and recovery records. You supply this information. Easy Quote does not require a developer-managed account, operate a public cloud workspace or synchronization service, include advertising or analytics, or automatically send business records to the developer.

公司、银行账户、客户、产品／设备、图片、项目及报价／PI／CI 单据保存在你的 Windows 电脑，并保留已保存修订、本机预览与恢复记录。资料由你录入。应用无需开发者自建账号，不提供公开云端工作区或同步服务，不含广告或遥测分析，也不会自动把业务资料发送给开发者。

New workspaces in Windows 1.0.6 and later contain no built-in test records. Updates preserve existing records rather than remove records created or imported in older versions. Editing and PDF generation run locally. The app includes no model, hosted AI, OCR or online translation service.

Windows 1.0.6 及以后版本的新工作区不内置测试资料。升级保留已有记录，不会清除旧版创建或导入的资料。编辑和 PDF 生成在本机进行；应用不包含模型、托管 AI、OCR 或在线翻译服务。

Selected files, clipboard and snapshots / 所选文件、剪贴板与快照

File and folder pickers access the locations you select for imports, images, PDF/page-image exports, workspace files, library ZIPs and optional Agent snapshots. Image paste reads the clipboard when you invoke it; copying Agent instructions writes the requested connection text to the clipboard. No background clipboard monitoring is used.

导入、图片、PDF／逐页图片导出、工作区文件、资料库 ZIP 和可选 Agent 快照通过文件／文件夹选择器使用你指定的位置。主动粘贴图片时读取剪贴板，复制 Agent 接入说明时写入对应连接文字，不在后台监控剪贴板。

Exports and snapshots may include private company, bank, customer, image and document information. They are separate files under your control, not automatic developer uploads. A normal workspace backup or ZIP file is not a promise of encrypted storage. Protect and review these files before sharing. Later app changes do not automatically update a previously exported snapshot.

导出和快照可能包含私有公司、账户、客户、图片与单据信息，是由你控制的独立文件，不会自动上传给开发者。普通工作区备份或 ZIP 文件不等于加密存储，请妥善保管并在分享前检查内容；应用后续修改不会自动更新已导出的快照。

User-initiated QR and LAN transfer / 主动二维码与局域网传输

When you select records for offline transfer, the app compresses and encrypts that selection and displays or saves transfer codes. A system-generated long code, normally conveyed by a separate unlock QR code, decrypts the package. The receiver previews and confirms import. Offline QR transfer uses no internet relay. Windows reads files or QR images selected by you rather than continuously scanning a camera.

主动选择离线发送资料时，应用压缩、加密所选内容并显示或保存传输码；系统生成的长码通常通过独立解密二维码传递，用于解密资料包。接收端预览并确认导入。离线二维码不通过互联网中继；Windows 读取你选择的文件或二维码图片，不持续调用相机扫描。

For LAN transfer, the sender temporarily listens on the selected local network address and shares pairing information. The receiving device connects directly. Devices exchange a device name, confirmation code, transfer metadata and encrypted selected records. Check the code on both devices and approve on the sender before transfer. The receiver is responsible for its imported copy. Pairing information may reveal local connection details; the transfer package together with its unlock code grants access to the selected records.

局域网传输时，发送端临时监听所选本地地址并提供配对信息，接收设备直接连接。两端交换设备名称、确认码、传输元数据和加密的所选资料。请在两端核对确认码，再由发送端批准。接收设备负责保管导入副本。配对信息可能包含本地连接详情；传输包与解密码合用可读取所选资料。

Paused sessions may retain local progress and material needed to resume. End sending or reset receiving to clear that session's recovery state. Transfers are initiated by you; this Store edition does not send records to a developer-operated public sync server.

暂停时可能在本机保留进度及续传所需资料；使用“结束发送”或“重新接收资料”可清除对应会话恢复状态。传输由你发起，商店版不把业务资料发送到开发者运营的公开同步服务器。

Microsoft Store purchases / 微软商店购买

Microsoft Store and Windows Store purchase APIs handle product availability, payment, subscription renewal, license checks and restoration. The app reads product identifiers, localized prices, purchase results and license status/expiration to determine formal PDF and image-export access. It does not receive your payment-card number, payment password or Microsoft sign-in password. Microsoft processes Store data under its privacy statement.

Microsoft Store 与 Windows 商店购买 API 处理商品展示、支付、订阅续费、许可校验及恢复。应用读取商品标识、当地价格、购买结果及许可状态／有效期，以判断正式 PDF 和图片导出权益；不接收支付银行卡号、支付密码或微软登录密码。微软按其隐私声明处理商店数据。

Windows and Apple purchases are sold and validated separately. Restoring a Windows purchase queries Microsoft Store; it does not upload company, customer or quotation records. Product availability is described on the support page and in the Store purchase confirmation.

Windows 与 Apple 购买分别销售和验证。恢复 Windows 购买会查询 Microsoft Store，不上传公司、客户或报价资料。商品开放状态见支持页及商店购买确认。

Optional reference-rate requests / 可选参考汇率请求

Manual refresh, or daily refresh when enabled, requests public reference rates over HTTPS from ECB and, if needed, Frankfurter. Requests use public rate endpoints and currency codes; they do not include customer, bank, quotation or image contents. Providers may process ordinary connection information, such as IP address and request time, under their own policies. Easy Quote does not receive those logs or use them for advertising. Disable daily refresh in Settings to fetch only when you choose Refresh, or use manual rates.

手动刷新，或启用每日刷新时，应用通过 HTTPS 向 ECB、必要时向 Frankfurter 请求公开参考汇率。请求使用公开汇率接口与币种代码，不附带客户、账户、报价或图片内容。服务方可能按各自政策处理 IP 地址、请求时间等正常连接信息；应用不接收这些日志，也不用于广告。“设置”关闭每日刷新后，仅在主动刷新时请求；也可手工设置汇率。

Optional external Agent tools / 可选外部 Agent 工具

The standalone CLI/MCP companion is optional and requires your local configuration. Local Tools can publish a separate workspace snapshot to a folder you choose and copy connection instructions. The snapshot may include company and bank details, customers and source images. An Agent you configure can read the snapshot through tools you authorize. The app does not silently connect it to your live workspace or send your business data to a model service.

独立 CLI／MCP 工具为可选功能，需要你在本机配置。“本地工具”可将独立资料快照发布到你指定的文件夹并复制接入说明，其中可能含公司、银行、客户和原始图片。你配置的 Agent 可通过获授权的工具读取该快照；应用不会静默连接实时业务库，也不会自行向模型服务发送业务资料。

If you give content or tool access to an external Agent or model provider, that provider's terms and data controls govern its processing. Review the files and authorization scope first. Connection/self-check permission does not authorize generating or replacing documents, sending files or uploading records; provide those instructions separately. Later GUI edits require a fresh snapshot when you want them available to the Agent.

若你向外部 Agent 或模型服务提供内容或工具访问权限，其处理方式受对应服务方条款与数据设置约束。请先检查文件与授权范围。连接／自检授权不包含生成或覆盖单据、发送文件或上传资料，这些动作需另行明确指示。后续界面修改需要重新准备快照，才能交给 Agent 使用。

Retention and removal / 保留与删除

Archive retains records. Deleting a supported saved library record, project or document moves it out of active lists into the app's Recycle Bin for restoration; it is not secure erasure. Historical document snapshots, source assets and external exports/backups are not erased by removing an active record. You control separately saved copies and copies shared with other devices or tools. The developer has no hosted business-data backup to recover or delete for you.

归档会保留资料。删除受支持的已保存资料库记录、项目或单据会将其从活动列表移到应用“回收站”，可供恢复，不属于安全擦除。移除活动记录不会抹除历史单据快照、原始素材或外部导出／备份。独立文件以及共享给其他设备或工具的副本需由你自行管理；开发者没有托管业务备份可代为恢复或删除。

Opening this page does not upload the app workspace. If you email support, we receive the message and attachments you choose to send to investigate your request. Use fictional examples; avoid passwords, full bank details and customer files.

本页由 GitHub Pages 托管，访问时浏览器会连接 GitHub，网站连接信息按其隐私声明处理；打开本页不会上传应用工作区。主动邮件联系支持时，我们会收到你发送的文字与附件以处理问题；请使用虚构例子，不要发送密码、完整银行资料或客户文件。
