Easy Quote · Privacy Policy

Windows edition · Updated 2026-10-08

Local records / 本机资料

Company, customer, bank-account, equipment, image and document data are stored on your Windows computer. Easy Quote does not operate a developer-managed account or cloud workspace, include advertising or analytics, or send your business records to the developer. It has no built-in AI, OCR or online translation.

公司、客户、银行账户、设备、图片和单据保存在你的 Windows 电脑。应用没有自建账号、云端工作区、广告、遥测分析、内置 AI、OCR 或在线翻译，也不把业务资料发送给开发者。

Microsoft subscriptions / 微软订阅

Microsoft Store handles purchase, payment, subscription management and licensing. The app reads Store product and license information to enable export. It does not receive your payment-card number or payment password. Microsoft handles Store data under its own privacy statement. Apple and Windows purchases are sold and validated separately.

购买、付款、订阅管理和许可由 Microsoft Store 处理。应用读取微软商品及许可信息以开放导出，不接收支付银行卡号或支付密码。Apple 与 Windows 分开销售和验证权益。

Optional exchange rates / 可选汇率

Manual or enabled daily refresh requests public currency rates from ECB and the fallback service Frankfurter. Requests contain currency codes, not your customer, bank, quotation or image contents. Providers may retain ordinary connection information, such as IP addresses and request times, for security and troubleshooting. Easy Quote does not receive those logs or use them for advertising. Disable daily refresh to request rates only when you choose Refresh, or use manual rates.

手动刷新或启用每日刷新时，应用向 ECB 和备用服务 Frankfurter 请求公开汇率，只发送币种代码，不附带客户、账户、报价或图片内容。服务方可能保留 IP、请求时间等正常连接记录用于安全和排障；应用不接收这些日志，也不用于广告。关闭每日刷新后，仅在主动刷新时联网；也可手工设置汇率。

Clipboard, files and backups / 剪贴板、文件与备份

Image paste reads the clipboard when you invoke it. File pickers read files you select. Exports, ZIP backups and optional Agent snapshots are saved where you choose. Snapshots are separate copies and may contain private company or bank material; you control whether another program reads them or whether you share them. Archiving keeps records. Removing a library reference does not erase historical document snapshots or exported copies. The developer has no hosted copy to recover.

点击粘贴图片时读取剪贴板；文件选择器读取你选中的文件。导出、ZIP 备份及可选 Agent 快照保存到你指定的位置。快照是独立副本，可能包含私有公司或银行资料，是否交给其他程序或分享由你决定。归档保留资料；移除资料库引用不会删除历史单据快照或外部导出副本。开发者没有托管副本可用于恢复。

This policy website / 政策网页

This page is hosted on GitHub Pages. Visiting it connects your browser to GitHub, which processes website connection data under its privacy statement. Opening this policy does not upload your app workspace.

本页由 GitHub Pages 托管，浏览器访问时会连接 GitHub，由 GitHub 按其隐私政策处理网站连接信息；打开政策页不会上传应用工作区。
