Easy Quote · Windows Support

Windows edition · Updated 2026-10-18

Create quotations (QT), proforma invoices (PI) and commercial invoices (CI) with your local company, customer and product records.

使用本机公司、客户和产品资料，制作报价单（QT）、形式发票（PI）和商业发票（CI）。

Public Store releases and internal test updates may have different version numbers. The project, library and recovery workflow below covers Windows 1.0.6 and later. Check your version in Windows Settings → Apps → Installed apps.

公开商店版与内部测试更新的版本号可能不同。以下项目、资料库和恢复流程适用于 Windows 1.0.6 及以后版本；可在 Windows“设置 → 应用 → 已安装的应用”核对版本。

Projects and documents / 项目与单据

Start with New Quotation. Project navigation groups QT, PI and CI separately, so you can select a document directly. Save a quotation revision, generate PI, then confirm the PI to create CI. CI has its own shipment information and actual prices. Each document keeps its own revisions and exported files. Preview and export use the same local PDF engine.

从“新报价”开始；项目导航按报价、PI、CI 分组，直接选择单据。保存报价版本后“生成 PI”，再“确认此 PI 并生成 CI”；CI 单独填写发货信息和实际价格。各单据分别保留修订与导出文件，预览与导出使用同一本机 PDF 引擎。

The interface supports Simplified Chinese, English, Russian, French, Japanese and Spanish. Document labels support English, Chinese, Spanish and French; you supply the business text. Changing interface language does not translate your content. Documents support equipment, prices, technical attachments and company showcase pages.

界面支持简中、英、俄、法、日、西；单据栏目支持英、中、西、法。业务文字由你填写，切换界面语言不会翻译内容。单据支持设备、价格、技术附件和公司展示页。

New records and recovery / 新建资料与恢复

New workspaces in 1.0.6 and later start empty, without built-in test records. Open Library, choose Equipment, Company Set or Customers, use the category-specific Add action, enter the fields and Save. Add bank accounts inside the company form. A new quotation needs a company, a bank account and a product.

1.0.6 及以后版本的新工作区为空，不内置测试资料。打开“资料库”，选择“设备／公司套装／客户”，点击对应“新增”按钮，填写后“保存”；银行账户在公司表单内添加。新报价需要公司、收款账户和产品。

Use the saved record's Delete action, or Project Actions → Delete Current Document / Delete Current Project. Confirmed deletions move to Recycle Bin in the sidebar; select an item and Restore Selected. Deleting a document also moves its derived documents to the bin. Restoring a project does not restore documents deleted separately beforehand. Historical snapshots, source assets and external exports remain. Discarding a newly added, unsaved record does not put it in Recycle Bin. Updating the app does not automatically erase existing records.

已保存资料使用对应“删除”按钮；项目和单据使用“项目操作 → 删除当前单据／删除当前项目”。确认后移入侧栏“回收站”，选择记录并“恢复所选”。删除单据时，其后续派生单据一并移入；恢复项目不会恢复此前单独删除的单据。历史快照、原始素材和外部导出保留，取消尚未保存的新增资料不会放入回收站；升级不会自动清空已有资料。

Export and purchases / 导出与购买

Select a document, then use the fixed Export button at the upper right → PDF or Page Images ZIP, and choose a save location. The Microsoft Store edition requires a valid Windows export entitlement: an active subscription, or a supported lifetime purchase when offered. Editing, preview and workspace/library backups do not require that entitlement.

选中单据后，点击右上常驻“导出 → PDF／逐页图片 ZIP”，选择保存位置。Microsoft Store 版正式导出需要有效 Windows 权益：有效订阅，或开放后购买的受支持买断权益。编辑、预览和工作区／资料库备份无需该权益。

Open Workspace & Subscription → Subscription & Restore Purchases to display Formal Export, then choose Restore Purchases. Sign into Microsoft Store with the account used for the Windows purchase, finish and close the Microsoft purchase dialog, then restore again if the license has not appeared. If it still fails, send the app version and exact error; do not purchase repeatedly. Windows and Apple purchases are sold and validated separately and do not unlock each other's apps.

打开“工作区与订阅 → 订阅与恢复购买”，在“正式导出”窗口点击“恢复购买”。Microsoft Store 须登录原购买账号；完成并关闭微软购买弹窗后，如权益尚未出现可再恢复。仍失败请反馈版本和完整错误提示，不要反复购买。Windows 与 Apple 权益分别销售、分别验证，互不解锁。

Only plans returned by Microsoft Store in the app are currently available. The Store confirmation shows the local price and renewal terms. The US$99.99 lifetime option is not yet on sale. A lifetime purchase, when available, will not automatically cancel an existing subscription. Manage or cancel subscriptions through Microsoft account services and subscriptions.

当前仅可购买应用内 Microsoft Store 返回的套餐，方案、当地价格和续费条款以系统确认页为准。99.99 美元买断选项尚未开放销售；后续购买买断版也不会自动取消已有订阅。管理或取消请使用微软账号订阅页面。

Backups and device transfer / 备份与跨设备传输

In Workspace & Subscription, Export Current Project or Export Complete Workspace creates a portable .easyquote file including the corresponding projects, revisions and referenced assets. Export Library ZIP migrates reusable company, equipment and customer records. Import the matching file on another device. Keep your own backup; editing document parameters does not rewrite library records.

在“工作区与订阅”选择“导出当前项目／导出完整工作区”，保存包含对应项目、修订和引用素材的 .easyquote 文件；“导出资料库 ZIP”用于迁移公司、设备和客户资料。在另一台设备导入对应文件。请自行保留备份；单据内编辑参数不会回写资料库。

  • Offline QR: select records in Offline Transfer and generate transfer codes. Once the receiver has the complete package, show the separate unlock code. Windows receives a saved .easyquoteqr file or QR images in Offline Code Import, decrypts from an unlock-code image (or the backup manual long code), then previews before Confirm Import. Windows currently reads files/images rather than a continuous camera stream.

    离线二维码：在“离线传资料”选择资料并生成传输码；接收端收齐后，发送端显示独立解密码。Windows 在“离线码导入”读取 .easyquoteqr 文件或二维码图片，使用解密码图片（或备用手动长码）解密，预览后“确认导入资料”。Windows 当前使用文件／图片接收，不是持续相机扫码。

  • LAN: connect both devices to a reachable local network. Use LAN Transfer to generate a pairing code; Windows accepts code text or its QR image in LAN QR Import. Compare the confirmation code on both devices, approve on the sender, then preview and import. A firewall may require permission for this app on a trusted private network; do not disable the firewall.

    局域网：两端连接可互通的本地网络；发送端“局域网传资料”生成配对码，Windows“局域网扫码导入”可输入配对码或读取配对码图片。两端核对确认码，发送端批准后传输，接收端预览并导入。防火墙可能需要允许本应用在可信专用网络通信，无需关闭防火墙。

These are user-initiated transfers, not automatic public cloud synchronization. The transfer codes together with the unlock code grant access to the selected records; share them only with the intended recipient.

以上为用户主动传输，不是公开云端自动同步。传输码与解密码合用可读取所选资料，请仅交给预期接收方。

Reference rates / 参考汇率

ECB rates, with Frankfurter as fallback, are daily references, not live bank trading prices. Refresh does not change entered product prices; Apply records the selected rate for the quotation. Disable daily refresh in Settings or enter a manual CNY-per-foreign-unit rate when offline.

ECB 及备用 Frankfurter 汇率为日度参考，不是银行实时成交价。刷新不会改变已填产品单价；“采用”才把参考率记录到报价。“设置”可关闭每日刷新；离线时可手工填写每单位外币兑人民币汇率。

Optional external Agent / 可选外部 Agent

Standalone CLI/MCP companion tools are separate from the Store app and require local setup. In Local Tools, select the companion folder and Copy Agent Connection. Choose where to publish a workspace snapshot and configure your own Agent to use it. The copied instructions authorize connection and a local check only; generating documents, replacing files or uploading data requires your separate instruction.

独立 CLI／MCP 工具另行配置，不随商店应用自动接入。在“本地工具”选择独立工具文件夹并“复制 Agent 接入说明”，指定资料快照位置后，再配置你自己的 Agent。接入说明只授权连接和本机自检；生成单据、覆盖文件或上传资料需要另行明确授权。

To request the standalone Windows x64 toolkit, email support@egretiva.com with your app version and Windows processor architecture. Support supplies the toolkit separately; extract it and select that folder in Local Tools.

需要 Windows x64 独立工具包时，请向 support@egretiva.com 提供应用版本和 Windows 处理器架构，申请当前工具包。由支持单独提供，解压后在“本地工具”选择该文件夹。

The snapshot is a separate copy; later GUI edits do not update it automatically. A local check does not prove that an Agent loaded the tools. Easy Quote includes no model, hosted AI, OCR or online translation service. Your Agent provider's terms and data settings apply when you choose to send it content.

快照是独立副本，后续界面修改不会自动更新快照。本机自检不能证明 Agent 已加载工具。应用不包含模型、托管 AI、OCR 或在线翻译服务；主动向外部 Agent 提供内容时，适用所选服务方的条款与数据设置。
