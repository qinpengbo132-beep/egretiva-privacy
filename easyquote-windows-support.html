Quotations and PI / 报价与 PI

Create separate quotation and proforma-invoice revisions with equipment, prices, technical attachments and company showcase pages. The interface supports Simplified Chinese, English, Russian, French, Japanese and Spanish. Document labels support English, Chinese, Spanish and French; you supply the business text. UI language does not translate your document content.

报价与 PI 分别保存修订，支持设备、价格、技术附件和公司展示页。界面支持简中、英、俄、法、日、西；单据栏目支持英、中、西、法，业务文字由用户填写。切换界面语言不会翻译单据内容。

Subscription and restoration / 订阅与恢复

Open Workspace & Subscription → Subscription & Restore Purchases. Use the Microsoft account that purchased the Windows subscription. Editing, preview, archive and workspace/library backups remain available without an export subscription. PDF and page-image export require an active Windows subscription. Manage or cancel through Microsoft account services and subscriptions. Mac purchases do not unlock Windows.

在“工作区与订阅 → 订阅与恢复购买”核对 Windows 权益，使用购买时的微软账号。编辑、预览、归档和工作区／资料库备份无需导出订阅；PDF 和逐页图片导出需有效 Windows 订阅。管理或取消请使用微软账号的订阅页面；Mac 购买不解锁 Windows。

Migration / 资料迁移

Export the complete workspace for projects, document revisions and records, or export Library ZIP for equipment/company/customer presets. Import the matching file on another device. Keep a backup before updates. An imported project owns editable copies of parameters, so quote edits do not rewrite your presets.

项目、修订和记录使用“导出完整工作区”；只迁移设备、公司和客户预设时使用“导出资料库 ZIP”。在另一台设备导入对应文件。更新前保留备份；报价参数是可编辑副本，逐单修改不会回写预设。

Rates and documents / 汇率与文件

Rates are daily references, not live bank trading prices. Refreshing does not change entered equipment prices; Apply explicitly records a rate for the current quote. If online refresh is unavailable, enter a manual CNY-per-foreign-unit rate. Quote and PI export are separate files. Preview is generated from the same PDF engine used for export.

汇率为日度参考值，不是银行实时成交价。刷新不会改变已填单价；“采用”才把参考率记录到当前报价。联网不可用时可手工输入每单位外币兑人民币的汇率。报价与 PI 分别导出，预览与导出共用 PDF 引擎。

External Agent / 外部 Agent

Install the optional companion tools separately. In Local Tools, choose that folder and Copy Agent Connection. The copied message points to the exact workspace snapshot, MCP configuration, Skill and CLI. A local doctor/probe proves those tools work, not that a particular Agent has loaded them. The app contains no model or translation service.

独立工具另行配置。在“本地工具”选择其文件夹并复制 Agent 接入说明；说明给出资料快照、MCP、Skill 和 CLI 的准确位置。本机自检不能证明某个 Agent 已加载配置，应用不包含模型或翻译服务。
