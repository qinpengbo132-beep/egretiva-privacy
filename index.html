WhatsApp 翻译助手 隐私政策

更新日期：2026-07-23

本扩展尊重并保护用户隐私：

  1. 本扩展不收集、存储或传输任何用户数据到开发者自有服务器用于统计或广告，不含任何统计与广告 SDK。
  2. 用户的设置（包括 DeepSeek API Key）、术语表、会话语言偏好与译文缓存，仅保存在用户本地浏览器（chrome.storage）中。
  3. 本扩展使用 Egretiva 统一账号服务（account.egretiva.com）完成登录与权益校验：登录在 Chrome 官方授权窗口中完成，扩展不接触账号密码；登录所需的邮箱地址仅用于账号验证与产品权益签发。
  4. 为实现翻译功能，用户查看或输入的聊天文本会发送至 DeepSeek（api.deepseek.com）进行翻译处理，传输内容由 DeepSeek 的隐私政策约束；除上述目的外，聊天内容不会发送给任何其他方。
  5. 云备份功能中，由用户主动上传的备份数据在设备端完成加密后，以密文形式经 data-cn.egretiva.com 网关传输至位于腾讯云的对象存储；服务端不持有明文数据与解密密钥。备份数据保留 30 天（Translator 为 90 天），删除后进入 14 天软删除恢复窗口；存储配额为 Desktop 2GB、Follow-up 20MB、Translator 50MB。
  6. 翻译代理：Egretiva 新用户试用模式下，用户选择翻译的文本会经 Egretiva 翻译代理转发至 DeepSeek API；BYOK（自带 API Key）模式下，文本不经过 Egretiva 服务器，直接发送至 DeepSeek。试用代理不记录翻译正文，仅记录字符用量；试用限额为 14 天、每日 2 万字符、累计 10 万字符。
  7. 用户可随时在扩展设置页退出登录、删除 API Key，或在浏览器中卸载扩展以移除全部本地数据。
