WhatsApp 翻译助手 隐私政策

更新日期：2026-07-19

本扩展尊重并保护用户隐私：

  1. 本扩展不收集、存储或传输任何用户数据到开发者自有服务器用于统计或广告，不含任何统计与广告 SDK。
  2. 用户的设置（包括 DeepSeek API Key）、术语表、会话语言偏好与译文缓存，仅保存在用户本地浏览器（chrome.storage）中。
  3. 本扩展使用 Egretiva 统一账号服务（account.egretiva.com）完成登录与权益校验：登录在 Chrome 官方授权窗口中完成，扩展不接触账号密码；登录所需的邮箱地址仅用于账号验证与产品权益签发。
  4. 为实现翻译功能，用户查看或输入的聊天文本会发送至 DeepSeek（api.deepseek.com）进行翻译处理，传输内容由 DeepSeek 的隐私政策约束；除上述目的外，聊天内容不会发送给任何其他方。
  5. 用户可随时在扩展设置页退出登录、删除 API Key，或在浏览器中卸载扩展以移除全部本地数据。

联系方式：support@egretiva.com
