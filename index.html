WhatsApp 翻译助手 隐私政策

更新日期：2026-07-25

本扩展尊重并保护用户隐私：

  1. 本扩展不收集、存储或传输任何用户数据到开发者自有服务器用于统计或广告，不含任何统计与广告 SDK，不做行为追踪。
  2. 用户的设置（包括 DeepSeek API Key）、术语表、会话语言偏好与译文缓存，仅保存在用户本地浏览器（chrome.storage）中。
  3. 基本翻译（自带 DeepSeek API Key）无需登录 Egretiva。用户主动使用 Egretiva 账号入口时，本扩展通过 Egretiva 统一账号服务（account.egretiva.com）完成登录与权益校验：登录在 Chrome 官方授权窗口中完成，扩展不接触账号密码；邮箱地址仅用于账号验证与产品权益签发。
  4. 为实现翻译功能，用户查看或输入的聊天文本、以及用户主动选中的网页文本（划词翻译，默认关闭、需手动开启）会发送至用户所选的翻译来源进行处理：
    • 使用自带 DeepSeek API Key 时：文本直接发送至 DeepSeek（api.deepseek.com），传输内容由 DeepSeek 的隐私政策约束；
    • 使用 Egretiva 托管 API 时：文本经 Egretiva 数据面（data-cn.egretiva.com）转发完成翻译并返回译文，Egretiva 不将原文与译文用于翻译之外的目的。
    除上述目的外，聊天内容与选中文本不会发送给任何其他方。
  5. 用户可随时在扩展设置页退出登录、删除 API Key，或在浏览器中卸载扩展以移除全部本地数据。
