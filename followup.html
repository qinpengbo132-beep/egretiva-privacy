CRM Followup 隐私政策

更新日期：2026-07-25

CRM Followup（客户跟进助手）尊重并保护用户隐私：

  1. 本应用采用本地优先架构：您录入的客户资料、跟进记录、统计数据全部保存在您自己的设备上（macOS 应用沙箱容器内），离线可正常使用全部基础功能。
  2. 本应用不收集、存储或传输任何用户数据到开发者自有服务器用于统计或广告，不含任何统计与广告 SDK，不读取您的通讯录、聊天记录或设备上其他应用的数据。
  3. 本应用使用 Egretiva 统一账号服务（account.egretiva.com）完成登录与权益校验：登录在系统浏览器中完成，应用不接触账号密码；登录所需的邮箱地址仅用于账号验证与产品权益签发。
  4. 云备份（可选功能）：由您主动开启的备份数据在设备端完成加密后，以密文形式经 data-cn.egretiva.com 网关传输至位于腾讯云的对象存储；服务端不持有明文数据与解密密钥。备份数据保留 30 天，删除后进入 14 天软删除恢复窗口；存储配额为 20MB。
  5. AI 助手（可选功能）：您可以自行配置第三方大模型 API Key（DeepSeek、Kimi 或其他 OpenAI 兼容端点），此时您选择分析的文本直接发送至您配置的服务商，不经过 Egretiva 服务器，受其各自隐私政策约束；若您选择 Egretiva 托管额度，文本会经 Egretiva 代理转发至大模型 API，代理不记录正文，仅记录字符用量。
  6. 您可随时在应用设置页退出登录、删除 API Key 与云端备份，或卸载应用以移除全部本地数据。
